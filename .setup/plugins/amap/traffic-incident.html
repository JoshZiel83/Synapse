交通事件 最后更新时间: 2024年08月06日

产品介绍

交通事件查询接口可以获取授权城市有效事件，包括事故、施工、管制等信息。与导航结合为用户提供智能化的出行方案、避让问题路段；语音播报提升行车安全，让路径动态尽在其掌控。主要用于事件图层渲染、统计、融合计算等场景。支持全国360+城市，更新频率2分钟。

说明

交通事件接口属于商业化接口，如需申请请通过 工单 进行商务咨询。

使用限制

使用城市/区域授权+时间包年方式，有每日访问量/QPS限制

使用说明

1

2
第二步

成为开发者并创建 Key 

为了正常调用 Web 服务 API ，请先注册成为高德开放平台开发者，并申请 Web 服务的 key ，点击具体操作。
